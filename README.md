# Silent Strokes — Art & Creative Studio Portfolio

A modern, responsive portfolio and studio management platform built with **React, Vite, and Firebase**, designed to blend storytelling with functionality. The project showcases my original artworks, provides a seamless commission and inquiry experience for visitors, and includes a secure private studio dashboard for managing client interactions.

Rather than being a conventional portfolio, Silent Strokes focuses on creating an immersive experience through carefully crafted layouts, subtle animations, and an earthy visual identity that reflects the personality of the artist behind the work.

# Getting Started

## 1. Clone the Repository

```bash
git clone https://github.com/akshita568/silentStrokes.git
cd silentStrokes
```

---

## 2. Install Dependencies

```bash
npm install 
```

---

## 3. Start Development Server

Firebase configuration is already integrated into the project, so no additional environment variables are required for local development.

```bash
npm run dev
```

The application will start at:

```
http://localhost:5173
```

# Design
The visual identity of Silent Strokes is inspired by traditional sketchbooks and artist studios.

The project focuses on:

- Minimal distractions
- Soft earthy color palettes
- Elegant typography
- Balanced whitespace
- Smooth interactions
- Story-driven presentation

Every section is designed to feel like turning the pages of an artist's journal rather than browsing a standard portfolio.
